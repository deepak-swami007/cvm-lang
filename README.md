# CVM++

`CVM++` is a tiny custom language project built in C++. This starter is intentionally small: it already runs the first milestone, `print 1 + 2 * 3;`, and the code is split into the same stages you will keep using as the language grows.

## Current Pipeline

```txt
source code -> lexer -> parser -> AST -> bytecode compiler -> VM -> output
```

What works right now:
- number literals
- `+`, `-`, `*`, `/`
- parentheses
- `print ...;`
- bytecode execution on a stack-based VM

## Build And Run

```bash
make run
```

Or build manually:

```bash
clang++ -std=c++20 -Wall -Wextra -pedantic -Iinclude src/*.cpp -o build/cvm
./build/cvm examples/first.cvm
```

When the program runs, it prints:
- the source
- the token stream
- the AST
- the generated bytecode
- the final VM output

That makes it much easier to learn how each layer connects to the next one.

## What To Read First

Open the files in this order:

1. `src/main.cpp`
   This shows the full flow from source text to final execution.
2. `include/cvm/token.h` and `src/lexer.cpp`
   This is the easiest entry point because it turns text into tokens.
3. `include/cvm/ast.h` and `src/parser.cpp`
   This shows how tokens become a structured syntax tree.
4. `include/cvm/bytecode.h`, `src/compiler.cpp`, and `src/vm.cpp`
   This is where the AST becomes instructions and the VM executes them.

## Good Next Steps

Add features in this order:

1. expression statements
2. unary minus edge cases and better errors
3. variables with `let x = ...;`
4. identifier lookup
5. comparisons like `<` and `==`
6. `if` and `while`
7. input support

Keep the rule simple: add one syntax feature, then thread it through all stages.
