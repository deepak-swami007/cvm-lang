# CVM++

`CVM++` is a tiny custom language project built in C++. This starter is intentionally small: it already runs the first milestone, `print 1 + 2 * 3;`, and the code is split into the same stages you will keep using as the language grows.

## Current Pipeline

```txt
source code -> lexer -> parser -> AST -> bytecode compiler -> VM -> output
```

What works right now:
- number literals
- `true`, `false`, and `nil`
- global variables with `let name = value;`
- uninitialized declarations with `let name;`
- reassignment with `name = expression;`
- comparisons: `==`, `!=`, `<`, `<=`, `>`, `>=`
- unary operators: `-`, `!`
- `+`, `-`, `*`, `/`
- parentheses
- blocks with `{ ... }`
- `if / else`
- `while`
- `print ...;`
- strict runtime checks for invalid types, division by zero, and bad jumps
- execution step limit to stop runaway programs or infinite loops
- bytecode execution on a stack-based VM
- sanitizer-friendly build target

## Build And Run

```bash
make run
make sanitize
```

Or build manually:

```bash
clang++ -std=c++20 -Wall -Wextra -pedantic -Iinclude src/*.cpp -o cvm
./cvm examples/example.cvm
./cvm --max-steps 5000000 examples/example.cvm
```

If you do not pass a file, the runner looks for `examples/example.cvm` first and then `examples/first.cvm`.

When the program runs, it prints:
- the source
- the token stream
- the AST
- the generated bytecode
- the final VM output
